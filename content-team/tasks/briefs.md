# Briefs

The Researcher appends new briefs. The Analyst appends briefs that come out of
performance ("more of X because Y"). Everyone else reads.

## Format

Each brief is one block. Ids run B-001 upward and are never reused.

```
### B-000 — <one-line opening>
opened_by: researcher | analyst
found_on: YYYY-MM-DD
momentum: what is rising, and how fast — with the evidence
angle: the specific angle we would take, one line
payoff: the number or claim the content can actually deliver on
sources:
  - <url> (checked YYYY-MM-DD)
status: open | assigned | used | dropped
```

A brief with no source URL is not a brief. If the number cannot be linked, it
does not go in — the hook-writer will lead with it, and an unpayable hook is a
broken promise to the viewer.
